# Page Anatomy

Whole-page shapes, funnel pacing, and closes, consolidated from the nine archetype page recipes (winner corpus, adversarially refuted). Loads at the build step, before the design_plan commits a macrostructure and a footer; the archetype's page recipe refines the committed entry.

## Macrostructures — the page shapes winners ship

Commit one by name. Jobs: attention (A), understanding (U), proof (P), close (C); lengths in viewport-heights (vh).

- **`argument-scroll`** — one held promise, then the case argued beat by beat. Statement hero (A) → logo strip (P) → mechanism reveal, the mid-page climax (U) → benefits (U) → attributed quote (P) → CTA (C) → designed footer. Corporate variant: 15+ sections, late named-CTA climax; event variant: lineup as proof, FAQ as rest, invitation close — 9 sections ≈ 24 scroll beats. Minimalist / Corporate Luxury / Brutalist-event. (winner-verified — Terminal, Son Daven, FlowFest; shipped — Cuberto.)
- **`maison-scroll`** — instant paint; campaign frames or value chapters alternate with editorial blocks; commerce hides behind "Discover". Campaign hero (A) → value chapters with floating product (U+P) → emblematic-product beat (P) → boutique/appointment close (C) → tabular footer with the house tagline. Corporate Luxury / Editorial-warm commerce. (winner-verified — Delvaux, Truekind.)
- **`specimen-tour`** — the artifact demonstrates itself: one capability per section, sections as peers, proof distributed. Wordmark hero + thesis (A) → interactive demo (U) → capability sections, each a live demo (P; climax = most interactive panel) → stat beat (P) → hero CTA reprised (C) → credits footer. Anime.js pins eight `100lvh` panels, copy cross-fading in place; summary variant: highlights bento then per-theme deep dives, 30+vh (Apple, shipped). Bento / Bold-Maximal. (winner-verified — Anime.js v4, Exat.)
- **`capability-grid`** — the editorial descendant of bento. Dark display hero + dual CTA (A) → divided capability strip (U) → 12-column grid of feature cards carrying real product UI (P) → enterprise proof (P) → CTA band (C) → compact footer. Bento: SaaS, AI, enterprise. (winner-verified — Endex; shipped — Vercel, Linear.)
- **`standfirst-stack`** — reading-first; no preloader, no spectacle peak — the chrome carries the voice. Serif statement + sans standfirst (A) → belief/essay index (U) → release cards (P) → mission close (C) → tabular footer. Editorial-light: institutions. (winner-verified — Anthropic.)
- **`studio-reel`** — the studio spine. Identity hero (A) → manifesto line (U) → featured-work reel or morph-tile grid (P) → story/blog band (rest) → contact footer (C). Registers: cinematic (Exo Ape), live 3D (Lusion), warm-organic (Cyd Stumpel). Spatial Organic / Immersive / Bold-Maximal studios. (winner-verified.)
- **`gallery-stack`** — a text-only name card (A), one full-bleed project per viewport, masked-revealing (P), a bare footer cue (C). The hero holds no image — the first still below the fold is the reward. Minimalist portfolios. (winner-verified — Gabriel Contassot, Stefan Vitasović.)
- **`studio-index`** — loader morphs into the navbar; identity-statement hero (A) → about band (U) → one hover-charged work index (P) → spectacle contact close (C, climax at the bottom). Brutalist / Bold-Maximal portfolios. (winner-verified — Eloy Benoffi, Treize Grammes.)
- **`type-index`** — a corner counter boots (A) into a giant-type project index over WebGL imagery (P); no marketing hero; a click plays an in-engine route morph; an About overlay doubles as the footer (C). Experimental / Spatial Organic / Corporate-folio. (winner-verified — Aristide Benoist, Obys, Depo Luxe.)
- **`gated-reel`** — a costumed threshold (the ENTER ticket, also the sound gate) (A) → featured-work masthead (A, climax) → hold-and-drag filmstrip of treated stills, each with a jury pull-quote (P) → per-work detail (P) → contact close under the wordmark (C). Editorial-dark / Immersive: film, institutions. (winner-verified structure — Siena.)
- **`portrait-procession`** — corner-locked wordmark over a full-bleed portrait (A) → full-viewport facet chapters, one pinned horizontal interlude, short bridge rests (U+P) → valediction footer bookending the hero (C); palette flips light→dark once, at the close; climax doubled: mid-page gallery + the close. Immersive: personalities. (winner-verified — Lando Norris.)
- **`chapter-world`** — the cover is scene one: wordmark, byline, entry CTA over a live canvas (A) → chapter select (U) → chaptered scenes, panel camera moves, physics (P, climax) → About (rest/C). Bold-Maximal / Experimental: story brands, exhibitions (media-only variant — Sculpting Harmony). (winner-verified cover — Ponpon Mania.)
- **`engine-world`** — the engine is the page; never commit without a WebGL path. Free-roam mode: no scroll — funnel jobs collapse into space: the world renders (A), secrets are discovered (P), an in-world sign-off closes (C) (winner-verified copy — Bruno Simon; technique — Messenger, Active Theory). Scroll-scrubbed mode: one continuous engine, shader seams, `scrollHeight` may pin at ~1vh, climax late and interactive, rest at a generative or contact close (winner-verified — Igloo Inc; single-source — Rogier de Boevé); variants: DOM type over a live 3D field (Lusion), pavilion glide (shipped — Cartier WAW). Experimental / Spatial Organic / Immersive / Corporate Luxury.

## The funnel — section jobs and pacing

**Every section commits its funnel job before it is built** — attention → understanding → proof → close — along with its intensity and its real visual. Sections composed one at a time without those commitments come out locally fine and globally level: a flat curve is a template however good each section looks alone.

Per-job rules, corpus-wide:

- **Attention** opens on one held subject — statement, portrait, wordmark, gate, or world — one line may hold a full viewport. Never a tile field, carousel, or centered-headline-plus-twin-CTA template (absent from all nine lines); labels + one manifesto line at most. The `<h1>` need not live here — Terminal's is the footer statement, Siena ships zero (winner-verified).
- **Understanding** states the mechanism in plain words, one idea per section, intensity 4–6. Spec-as-headline is allowed (Exat's "1715 glyphs per style"); feature-benefit paragraph blocks are not.
- **Proof** is attributed or demonstrated, never asserted: quotes carry name + role + org, stats carry labels and texture, work shows full-bleed or live. Proof may own the climax (Cuberto; Anime.js) — attention may not do proof's job by claiming.
- **Close** is one imperative plus a trust cue — availability, real address, heritage date — reprising the hero's CTA or contact; the footer is the close's final beat, not chrome after it.

Measured norms:

- **Section count:** 4–8 (studio-index) · 6–14 (minimalist) · 9 (FlowFest — earlier "24-section" reads counted scroll beats; corrected) · 15+ (Son Daven) · 40+ headings (Apple, the outlier).
- **Length:** 4–6vh (maison) → 7–11 (standfirst, agency) → 12–16.5 (demo reel; Lando 10369px / 630px viewport, winner-verified) → 30+ (Apple). Engine lines pin `scrollHeight` ≈ 1vh on 3 of 5 immersive winners (winner-verified).
- **Climax disagrees by line — commit a side:** mid-page mechanism reveal (Terminal) · ~40% lineup (FlowFest) · late interactive payoff (Igloo, Son Daven) · on-click (type-index) · doubled hero+footer (Lando) · at the footer itself (Eloy). Two lines refuse the spike: maison and standfirst run even intensity.
- **Rest** sits before or at the close — FAQ before the invitation, sponsors before the footer, blog before contact — plus mid-scroll voids (Terminal's 230px footer pad) and bridges (Lando's 857px/397px).

## Footers — the last designed moment

- **oversized-wordmark** — the page's largest type lands last, on a deep ground. Terminal puts the `<h1>` here: `.footer__wrapper{position:fixed;bottom:0;transform:translateY(100%)}` slides up over a 50vh height-holder while a dark overlay dims the outgoing page — a composed curtain (winner-verified). Also Depo Luxe, Siena's wordmark-contact close (winner-verified); Linear's tagline reprise (shipped).
- **CTA-reprise / contact-first** — the terminal action is the primary CTA or contact, plus a trust cue: "Have an idea?" → "Tell us" + dual real addresses (shipped — Cuberto); "Let's talk" + Bristol address + newsletter (winner-verified — Lusion); sales departments by city (winner-verified — Son Daven).
- **valediction-fold** — the cinematic bookend: full-bleed portrait, split-color oversized headline, signature, sponsor marquee, accent baseline strip; inverts the hero's palette in one flip (winner-verified CSS / shipped composition — Lando Norris).
- **footer-spectacle** — the loudest interaction lands last: Eloy's clone machine clones the connect CTA twice per 200px of cursor travel, capped ~200, `mix-blend-mode:difference`, staggered `back.in(1.7)` exit (technique — Codrops, corrected count).
- **tabular-index** — deep functional columns carrying the voice: Anthropic's nine columns on the theme-ivory ground, same-family hairline `border-top`, links in the display serif (winner-verified columns; CSS technique); Aristide's About-overlay: clients wall + awards ledger (winner-verified). Product/bento tolerates plainer chrome but adds a designed cue — Anime.js's sponsor-first block, instant fill-swipe hovers (winner-verified).
- **bare-cue / costumed credits** — a designed refusal: "SCROLL UP" (Gabriel), "2025." (Stefan), Siena's thin in-lexicon credits — valid only when the body already spent the spectacle (winner-verified).
- **in-world sign-off** — engine lines close inside the scene: Bruno's "Thank you for visiting my portfolio! — Bruno" (winner-verified); Igloo's copyright line baked into the HUD, no DOM footer (winner-verified); Cartier's in-world close (shipped).

**The anti-signal:** the link-columns-only template footer. Outside product/bento no winner ships one; inside it the columns still carry a designed cue. Standing preflight rule: the footer carries no presentation copy — provenance and brand-story live in the body presenting the subject; the footer moment is compositional — scale, ground, palette, one interaction — never extra prose.
