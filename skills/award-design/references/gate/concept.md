# R1 — the concept gate

Runs in a fresh context (a subagent where the harness has one; without subagents, emit the full artifact labeled `degraded: same-context`) after the direction contract exists and before any build file is written. The reviewer refutes; it never confirms. Every probe below produces a written verdict — a probe that vanishes without one is a skipped gate.

## Inputs

The design_plan (SPINES + SEED + contract), the brief, the tier-1 archetype file, `references/exemplars.md`, `references/signature-invention.md` (the bespoke test and the medium map judge against it). Nothing else — R1 judges the concept, not the corpus.

## The probes, in order

1. **Seed verification.** The SEED block quotes `direction_roll.py` stdout verbatim; rerun the printed reproduce command. A missing key, a non-reproducing index, or a contract built on a spine other than the assigned one (unless a challenger won its contest, stated) means the roll was skipped — a material finding ahead of any taste point.
2. **Predictability probe.** Before reading the contract, state the direction you predict from the category alone. A match with the built direction means it is still a default — the roll was laundered.
3. **Two-altitude test.** First order: could someone guess the palette and type from the category? Second order: could someone guess the aesthetic family from category-plus-anti-references? Either yes → rework, the reflex survived a tier deeper.
4. **The bespoke test.** Would the SIGNATURE block's mechanic sit unchanged on a rival's site in this archetype? A category signature (a scroll-reveal, a parallax, a magnetic button) is OFF-TRACK: regenerate it, never file it.
5. **Replay check.** The SIGNATURE block names its replay behavior. A fire-once effect that leaves a static frame is an entrance, not a signature.
6. **Premise veto.** Does the metaphor manufacture props a real brand at this tier would not ship? Coherent-but-clutter fails here whatever its internal logic.
7. **Palette lived A/B.** Judge the composed system at page proportions beside the exemplar's frame: role-coherence is not desirability, and a *clinical* verdict fails like a thin spine.
8. **Mood check.** Read each contract block: one that reads like a mood instead of a decision ("elegant, timeless") means the direction is not decided yet.

## Verdict

`ON-TRACK` (with any binding fixes, adopted as written) or `OFF-TRACK` (names the failing probe and the regeneration target — the spine, the signature, or the palette; polish is never the remedy). A regenerated concept re-enters at probe 1 with a different fresh reviewer where possible: a reviewer whose own suggestion was adopted cannot clear it.
