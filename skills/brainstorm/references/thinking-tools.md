# Thinking tools

On-demand techniques for the Diverge and Challenge phases. Read this only when the option set is thin or the recommendation feels anchored — not on every run.

## First-principles decomposition

Break the problem down to what is actually true, then rebuild.

- State the assumption under examination.
- Strip it to fundamentals — what is a hard constraint, what is convention?
- Rebuild using the fundamentals only.

Reach for this when thinking has gone incremental, or when "that's just how it works" goes unchallenged.

## Inversion

Solve the opposite problem to expose the real one.

- Ask "what would guarantee failure here?".
- List the failure-guaranteeing moves.
- Check the leading approach does none of them.

Reach for this to pressure-test a recommendation that looks clean.

## Reverse brainstorm

Generate the anti-solution, then flip it.

- Ask "how would we make this problem worse?".
- List every degrading move — more steps, more coupling, hidden state.
- Reverse each one; the inverse is a candidate fix.

Reach for this when divergence stalls and every idea looks the same. People spot what is wrong faster than what is right.

## Elimination

Subtract instead of add.

- For each component, ask "what breaks if this is gone?".
- Remove anything nobody would miss.
- Treat "remove it" as a first-class option, not a fallback.

Reach for this when every obvious approach adds surface. The strongest option often deletes.
